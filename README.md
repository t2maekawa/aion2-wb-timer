# AION2 リポップタイマー v0.5

## v0.5 変更点
- 11時間タイマーは、個別の基準時刻から11時間ごとにリポップを繰り返します。
- 6時間タイマーは、個別の基準時刻から6時間ごとにリポップを繰り返します。
- 表示するカウントダウンと通知時刻は常に次回リポップを基準にします。
- 各周期の30分前・10分前・リポップ時刻に通知します。
- 既存の通知音選択、音量設定、3回繰り返し再生、個別基準時刻保存を維持しています。

## 公開方法
GitHub Pagesで使っている既存の `index.html` を、このフォルダの `index.html` に差し替えてください。

## 周期の例
11時間タイマーの基準時刻が12:00の場合、最初のリポップは23:00、その次は翌日10:00、21:00、翌々日08:00…と続きます。
